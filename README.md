# Электронны слоўнік фемінітываў і фемініннай лексікі

**Электронны навуковы слоўнік фемінітываў і фемініннай лексікі ў творах Якуба Коласа (трылогія «На ростанях») і Мікалая Аляксеевіча Некрасава (паэмы «Мароз, Чырвоны нос», «Каму на Русі жыць добра»).**

---

## 🌟 Асноўныя магчымасці і функцыі

1. **Два тэматычныя слоўнікі**:
   - **Карпус М. А. Некрасава**: 19 навукова распрацаваных лексічных адзінак з паэм «Мароз, Чырвоны нос» і «Каму на Русі жыць добра» з аўтэнтычнымі цытатамі, граматычнымі і стылістычнымі паметамі, мадэлямі словаўтварэння.
   - **Карпус Якуба Коласа**: 20 лексічных адзінак з трылогіі «На ростанях» з поўным кантэкстам і аналізам сацыяльна-бытавой, прафесійнай і эмацыйнай лексікі.
2. **Аўтарскія візуальныя тэмы**:
   - Асобная атмасферная тэма для Некрасава (зімовая палітра, эмблема, радок «Есть женщины в русских селеньях...»).
   - Асобная тэма для Коласа (палеская прыродная палітра, эмблема, цытата «Прыгожая, поўная сілы і маладосці...»).
   - Падтрымка **Светлай** і **Цёмнай** тэмы з аўтаматычным захаваннем выбару.
3. **Разумны пошук і навігацыя**:
   - «Жывы» пошук без перазагрузкі старонкі.
   - Спецыяльная нармалізацыя для сумяшчальнасці беларускай і рускай літар: увод рускай `и` знаходзіць беларускую `і` і наадварот!
   - Віртуальныя клавішы для спецыфічных літар: `[ і ]`, `[ ў ]`, `[ ’ ]`, `[ ё ]`.
   - Фільтрацыя па алфавіце і вобласцях пошуку (у словах, у апісанні і мадэлях, усюды).
   - Выбранае (закладкі) з захаваннем у памяці браўзера.
4. **Адаптыўны дызайн**:
   - Поўная карэктная работа на смартфонах, планшэтах, ноўтбуках і шырокафарматных маніторах.

## 🔐 Сістэма доступу: Госць і Адміністратар

Сайт падзяляе правы звычайных чытачоў і адміністратара для абароны ад непажаданых змен:

### 1. Рэжым чытача (Госць)
- Даступны ўсім наведвальнікам па змаўчанні.
- Даступны поўны прагляд, пошук, фільтрацыя, алфавіт, даданне ў выбранае, капіяванне артыкулаў і экспарт у JSON.
- **Усе кнопкі рэдагавання, выдалення і дадання новых слоў схаваныя і недаступныя**.

### 2. Рэжым Адміністратара (Уваход у акаўнт)
- Уваход ажыццяўляецца праз кнопку **«Уваход»** у правым верхнім куце шапкі сайта (падказкі лагіна і пароля ў самім акне прыбраныя дзеля бяспекі).
- **Зыходны лагін**: `admin`
- **Зыходны пароль**: `admin123`
- *Пасля паспяховага ўваходу*:
  - У шапцы з'яўляецца індыкатар **«🛡️ Адміністратар»** і кнопка **«🔑 Пароль»**.
  - **Змяненне пароля**: націсніце кнопку «🔑 Пароль» (або клікніце на бэйдж адміністратара) — адкрыецца форма для праверкі старога і задання новага надзейнага пароля.
  - На кожнай слоўнікавай картцы з'яўляюцца кнопкі **«✏️ Рэдагаваць»** і **«🗑️ Выдаліць»**.
  - У дэтальным акне слова з'яўляецца кнопка **«✏️ Рэдагаваць»**.
  - У шапцы становіцца даступная кнопка **«+ Дадаць слова»** з падрабязнай формай запаўнення ўсіх лінгвістычных палёў (націск, часціна мовы, род, твор, граматыка, значэнне, словаўтваральная мадэль, стылістыка, цытаты).
  - Даступная кнопка хуткага выхаду **«Выйсці»**.

## 🚀 Размяшчэнне на GitHub Pages

Сайт цалкам гатовы для публікацыі на бясплатным хостынгу **GitHub Pages** (статычны сайт без серверных залежнасцей, выкарыстоўвае сучасныя Web API, уключаны `.nojekyll` і `404.html`).

### Пакрокавая інструкцыя размяшчэння:

#### Крок 1. Стварэнне рэпазіторыя на GitHub
1. Зайдзіце на [github.com](https://github.com) у свой профіль.
2. Націсніце кнопку **«New repository»** (Стварыць новы рэпазіторый).
3. Увядзіце назву (напрыклад: `feminitive-dictionary`).
4. Выберыце **Public** (Публічны).
5. Не стаўце галачкі на «Add a README file» (ён ужо ёсць у гэтай тэчцы).
6. Націсніце **«Create repository»**.

#### Крок 2. Адпраўка праекта на GitHub
Адкрыйце тэрмінал або PowerShell у гэтай тэчцы праекта (`dictionary-app`) і выканайце наступныя каманды:

```bash
git init
git add .
git commit -m "Першапачатковы рэліз электроннага слоўніка"
git branch -M main
git remote add origin https://github.com/ВАШ_ГІТХАБ_ЛАГІН/feminitive-dictionary.git
git push -u origin main
```
*(Замяніце `ВАШ_ГІТХАБ_ЛАГІН` на ваш лагін на GitHub)*.

#### Крок 3. Уключэнне GitHub Pages
1. У вашым рэпазіторыі на GitHub адкрыйце ўкладку **«Settings»** (Налады).
2. Злева ў меню абярыце раздзел **«Pages»**.
3. У блоку **«Build and deployment»**:
   - **Source**: выберыце `Deploy from a branch`.
   - **Branch**: выберыце галіну `main`, тэчку `/ (root)` і націсніце **«Save»**.
4. Праз 1–2 хвіліны старонка збярэцца, і ўверсе з'явіцца спасылка на ваш апублікаваны сайт:
   `https://ВАШ_ГІТХАБ_ЛАГІН.github.io/feminitive-dictionary/`

## 💾 Як захоўваць праўкі адміністратара для ўсіх карыстальнікаў

Калі вы, як адміністратар, рэдагуеце або дадаеце словы прама на сайце ў браўзеры, яны аўтаматычна захоўваюцца ў лакальнай памяці браўзера (`localStorage`).

Каб гэтыя змены назаўсёды захаваліся на самім сайце ў GitHub Pages і сталі бачнымі ўсім наведвальнікам:
1. Увайдзіце ў акаўнт адміністратара на сайце.
2. Унясіце патрэбныя змены (рэдагаванне, даданне новых слоў, выдаленне).
3. Націсніце кнопку **«База даных / Экспарт»** у шапцы сайта.
4. Адкрыйце ўкладку **«Экспарт у JSON»** і націсніце зялёную кнопку:
   **«Спампаваць dictionaries.js (для GitHub)»**.
5. Захавайце спампаваны файл у тэчку праекта: `data/dictionaries.js` (замяніўшы стары).
6. Адпраўце абноўлены файл на GitHub праз каманды:
   ```bash
   git add data/dictionaries.js
   git commit -m "Абнаўленне слоўнікавых артыкулаў"
   git push
   ```
7. GitHub Pages аўтаматычна абновіць сайт на працягу хвіліны, і ўсе наведвальнікі ўбачаць новыя словы!
